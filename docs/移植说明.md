# 亚瑟移植说明（在 VIKINGYFY/OpenWRT-CI 基座上）

这份树 = `leileia-bot/ax1800pro`（VIKINGYFY CI，源码 `VIKINGYFY/immortalwrt@owrt`，内核 6.18.60）
＋ 旧库 `JDCloud-RS` 的亚瑟定制层。

## 改了什么

| 位置 | 改动 |
| --- | --- |
| `package/arthur/` | 新增。亚瑟面板整包（温度三卡、USB 上网、ZRAM、12 格常用功能、网页终端入口、主机名/Logo、首页 dashboard） |
| `Scripts/PRIVATE.sh` | 不再删 argon（皮肤接在 argon 上）；改成删 vantage；新增搬运 `package/arthur` 并调用 `Scripts/arthur-theme.py` |
| `Config/PRIVATE.txt` | 主题改成 argon=y / vantage=n；新增 `luci-app-arthur=y`；NSS 九项保持全 `=n` |
| `Scripts/arthur-theme.py` | 新增。把亚瑟皮肤注入 Argon 模板：`theme.css`、`favicon.svg`、`arthur-shell-<构建号>.js`、登录页 `sysauth.ut`；任何锚点找不到只告警，不让构建失败 |
| `.github/workflows/QCA-ALL.yml` | `WRT_THEME: vantage` → `argon` |
| honk | 已整包移除（`PRIVATE.sh` 无 honk、`PRIVATE.txt` 无 honk、开机引导无 honk） |

## 亚瑟包为这套基座做的适配

- `arthur-performance`：新增 `nss_present()`，`auto` 模式在无 NSS 栈的基座上自动退化为 `software`，不会再出现 `nss_load_failed`；
- `performance.js`：去掉「NSS 自动兼容」选项与三行 NSS 专属状态（NSS 驱动 / 加速连接数 / 无线 NSS 驱动），文案改成软件分载口径；
- `dashboard.js`：`转发加速` 改叫 `转发分载`，去掉 ECM 判定；
- ZRAM 说明改成「取物理内存一半」，`91-arthur-performance` 里本来就是按 `/proc/meminfo` 算一半（1 GB → 512 MiB），不是写死 128 MiB；
- 脚注链接指向新库，`sysauth.ut` 的 Powered by 改成 `LuCI / immortalwrt / Argon`。

## 没搬过来的东西

- 旧库的 `build.sh`、`scripts/audit_packages.py`、发布脚本、`VERSION`/rc 号体系——它们的职责已被 `WRT-CORE.yml` 覆盖，两套并存会打架；
- 旧库的 `config.seed`（整份 seed 会把新基座的默认配置顶掉），只取了差异写进 `Config/PRIVATE.txt`；
- honk、NSS 硬件加速、NoWiFi 变体。

## 第一次跑的建议

1. 先 `TEST: true`：只生成 `.config`，核对 argon、`luci-app-arthur`、daede、ttyd、ZRAM 都在，NSS 九项全 `n`；
2. 再正式编：重点看 daede 与 dae 的内核态编译（6.18.60 上 eBPF/BTF 只能实测）；
3. 刷机后看首页：温度应为「SoC xx°C · Wi‑Fi xx°C · DDR xx°C」，常用功能 12 格，侧栏服务顺序 daede → OpenClash。
